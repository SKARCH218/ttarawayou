## 트레빗 (Travit)

**예산과 취향만 알려주면, 나머지는 AI가 정합니다. 그리고 장소는 도착하는 순간까지 비밀입니다.**

Travel + Trip + Navigator. 결정 피로 없이 떠나는 서프라이즈 여행 내비게이터입니다.

## 왜 만들었나

주말마다 "어디 갈까"만 이야기하다 결국 아무 데도 못 가는 일이 반복됐습니다.
주변 50명에게 물어보니 답이 같았습니다 — 갈 데가 없어서가 아니라, 정하는 게 귀찮아서 안 간다는 것.

기존 여행 앱은 더 많은 정보와 선택지로 이 문제를 풀어 왔지만, 사람들이 멈춰 서는 지점은
정보 부족이 아니라 결정 그 자체였습니다. 그래서 저희는 반대로 갔습니다.
**선택지를 늘리는 대신, 결정을 대신 가져옵니다.**

## 어떻게 쓰나요

1. **지역과 예산, 기간을 고릅니다** — 수도권(서울·경기·인천), 예산은 슬라이더로
2. **취향 질문 8개에 답합니다** — 한 화면에 하나씩. 목적, 성별, 연령대, 좋아하는 음식,
   많이 걷는 걸 좋아하는지까지. 마지막엔 "조용한 카페 위주로" 같은 **자연어 문장**을 그대로 받습니다
3. **AI가 플랜을 설계합니다** — 예산 배분과 추천 이유는 보이지만, **장소 이름은 가려져 있습니다**
4. **길을 따라갑니다** — 발밑의 길이 조금씩만 열립니다
5. **도착하면 공개됩니다** — 그 순간에야 이름·주소·평점이 나타납니다

## 핵심 기능

- **취향 기반 AI 일정 설계** — 프로필과 자연어 메모를 로컬 LLM에 넘겨 장소를 고르고 추천 이유까지 생성합니다
- **목적지 비공개 안내** — 도착 전까지 장소를 숨기고, 다음 구간의 경로만 조금씩 공개합니다
- **예산 자동 배분** — 숙박·관광·식비·교통으로 나누고 초과분은 자동으로 조정합니다
- **걷기 기피 반영** — "많이 걷기 싫다"고 답하면 산·트레킹 코스가 후보에서 빠집니다
- **시뮬레이션 모드** — GPS 없이도 여정을 1×/3×/10× 배속으로 돌려 도착 공개까지 체험할 수 있습니다

## 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 백엔드 | Kotlin + Spring Boot 3.5, JPA, H2 |
| 앱 | Kotlin Multiplatform + Jetpack Compose (Material 3) |
| 웹 | Vanilla JS + Leaflet (CARTO 타일) |
| AI | 로컬 LLM (LM Studio, OpenAI 호환 API) + 자체 휴리스틱 알고리즘 |
| 외부 API | TMAP POI·대중교통, 국토부 TAGO 실시간 버스, ODsay, OSRM |
| 배포 | 자체 서버 (VPN 터널링 + systemd) |

**AI가 멈춰도 서비스는 멈추지 않습니다.** LLM 응답이 늦거나 꺼져 있으면
평점·근접도·예산 제약 스코어링과 최근접 이웃 동선 최적화로 구성된 자체 알고리즘이 대신 동작합니다.
외부 API 키가 하나도 없어도 수도권 시드 데이터로 전체 흐름이 돌아갑니다.
