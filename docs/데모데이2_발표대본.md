> 서버 DB 기준 외부 가입자는 0명(10/7 14:50 확인). 13명은 가족·친구가 로컬 환경에서 써 본 인원으로 DB에는 안 잡힘.

## 1. 표지 [0:00–0:15]
안녕하세요, 아산스마트팩토리마이스터고 PLAYLABS입니다. 트레빗은 예산과 취향만 넣으면 AI가 여행을 정하고, 장소는 도착하는 순간까지 비밀로 남기는 앱입니다. 먼저 어떤 아이디어인지, 그다음 어떻게 구현했고 첫 데모데이 이후 뭐가 달라졌는지 말씀드리겠습니다.

## 2. 아이디어 — 왜 만들었나 [0:15–0:35]
시작은 인터뷰였습니다. 친구 30명과 가족들에게 물어보니, 여행을 안 가는 이유는 갈 데가 없어서가 아니라 정하기 귀찮아서였습니다. 가까운 곳도 코스를 못 짜고, 휴가가 있어도 어디 갈지 몰라서 집에 있고, 계획하다 지쳐서 포기합니다.

## 3. 아이디어 — 그래서 이렇게 [0:35–1:00]
그래서 정하는 걸 통째로 AI에게 넘겼습니다. 사용자는 질문 몇 개에 답하고 예산만 정합니다. 코스, 식당, 숙소, 동선은 AI가 전부 결정하고, 장소 이름은 가려 둡니다. 길만 조금씩 열리다가 도착한 순간 이름이 공개됩니다. 사용자는 따라가기만 하면 됩니다.

## 4. 아이디어 — 실제 화면 [1:00–1:25]
실제 화면입니다. 질문에 답하면 AI가 플랜을 짭니다. 예산 배분과 추천 이유만 보이고 장소 이름은 가려져 있습니다. 출발하면 비밀 경로가 조금씩 열리고, 도착하면 이름과 주소, 평점이 공개됩니다.
(라이브 시연은 여기서 하거나 생략. 추천 입력: 서울 · 2일 · 20만원 · 친구 · 관광 · 전통·역사 · 산책/사진 명소 · 적당히. 불안하면 녹화본)

## 5. 구현 — 무엇으로 만들었나 [1:25–1:55]
구현입니다. 앱은 코틀린 멀티플랫폼과 컴포즈로 만들어서 코드 하나로 안드로이드와 웹이 같이 나옵니다. 서버는 스프링 부트와 PostgreSQL입니다. AI는 장소 검색, 주변 장소, 거리를 도구로 직접 호출하면서 일정을 짭니다. 지도와 교통은 TMAP, 국토부 버스 API, OSRM입니다. AI가 실패하면 알고리즘이 대신 짜서 앱은 멈추지 않습니다.

## 6. 문제 ① AI가 너무 느렸다 ✔ [1:55–2:35]
가장 큰 문제는 AI였습니다. 첫 데모데이 때는 로컬 모델에 5분을 줘도 답을 못 끝냈습니다. 그래서 클라우드의 AI를 게이트웨이 API로 가져다 썼고, 오늘 실측에서 예산 30만 원, 2일 일정을 42초 만에 AI가 짰습니다. 예산의 89퍼센트를 쓰면서 추천 이유까지 직접 썼습니다. 4주 전엔 대부분 실패였고 지금은 됩니다. 아직 42초는 길어서 이걸 줄이는 게 다음 숙제입니다.

## 7. 문제 ②~⑤ 막힐 때마다 이렇게 풀었다 ⚠ [2:35–3:30]
이 밖에도 막힌 일이 있었습니다. AI는 방금 말씀드린 대로 풀었습니다. 둘째, 인증메일을 보내던 Gmail이 봇으로 판단돼 정지됐는데, 복구된 뒤에도 인증이 거부됐습니다. 그래서 메일이 막혀도 가입이 되도록 초대코드 경로를 새로 만들었습니다. 셋째, 무료 도메인이라 메일 발송 서비스를 못 씁니다. Resend가 무료 공용 도메인을 거부해서, Brevo나 도메인 구입을 비교하고 있고 지금은 Gmail을 씁니다. 넷째, SSL 인증서가 안 붙어서 HTTPS를 못 씁니다. 그래서 브라우저가 GPS를 막아서 오늘은 시뮬레이션 모드로 시연합니다. 이건 아직 못 풀었습니다. 다섯째, 대중교통 노선입니다. TMAP, ODsay, 국토부 버스 API를 조합했고, 실패하면 거리 추정으로 대체하고, 버스 대기시간은 국토부 API로 계산합니다. 다만 지도 API 무료 한도에 걸려서 오늘은 수도권 기준으로 시연합니다.
(⚠ 상태 칸은 해결/진행 중/미해결을 솔직하게 적은 것. 짧게 줄이려면 3번·4번 줄만 읽고 나머지는 슬라이드로 대체. TMAP 쿼터 429라 지방 지역을 라이브로 보여주려 하지 말 것)

## 8. 사용자 — 솔직한 숫자와 첫 후기 ✔ [3:30–4:15]
사용자 숫자는 솔직하게 말씀드리겠습니다. 회원가입 인증메일이 9월 7일부터 막혀서, 서버 DB에 남은 실제 가입자는 8주 동안 거의 0명이었습니다. 그래서 10월 6일에 초대코드로 가입하는 경로를 열었고, 가족과 친구 13명이 직접 써 봤습니다. 다만 로컬 환경에서 테스트한 거라 서버 DB의 가입자 수에는 안 잡힙니다. 그래서 '13명이 써 봤다'는 건 저희가 직접 확인한 숫자이고, 서버 숫자와는 따로 말씀드립니다.
후기 하나를 읽어 드리겠습니다. '주말에 갑자기 시간이 빌 때, 사는 지역을 잘 몰랐는데 앱 덕분에 잠깐 마실 겸 몰랐던 장소와 맛집에 갈 수 있었다. 맛집과 관광지를 검색하는 피로가 줄어서 좋았다.' 같은 의견이 더 있었습니다. 처음에 말씀드린 검색·계획 피로를 덜었다는 얘기라서 가장 반가웠습니다.
(주의: 13명은 팀이 구두로 확인한 숫자. 질문받으면 '서버 집계는 아니고, 직접 사용을 확인한 인원'이라고 그대로 답할 것. 후기는 사용자 원문을 다듬은 것)

## 9. 막힌 것·마무리 ✔ [4:15–5:00]
세 가지를 여쭙고 싶습니다. 하나, AI 응답 42초를 어떻게 줄일지. 둘, 지도 API 무료 한도입니다. 플랜 하나에 경로 조회가 여러 번 나가서 오늘 한도에 걸렸는데, 호출 수를 줄이거나 결과를 캐시하는 좋은 방법이 있을까요. 셋, 지도 데이터에서 박물관 유물 이름 같은 장소가 관광지로 섞여 나옵니다.
8주 동안 배운 건, 위험한 실패는 터지는 실패가 아니라 조용히 실패하는 것이라는 점입니다. 감사합니다.
