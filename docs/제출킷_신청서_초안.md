## 해결하려는 문제

여행 앱들은 '더 많은 선택지'를 주지만, MZ세대 72%는 결정 피로를 호소하며
"갈 데가 없어서가 아니라 **정하는 게 귀찮아서** 여행을 포기"합니다.
트레빗은 예산 입력 → AI 자동 설계 → 목적지 비공개 안내라는 역발상으로
결정 피로를 제거하고, 지역 소상공인에게 방문객을 자동 송객합니다.
서비스 지역은 수도권(서울·경기·인천)에서 시작합니다.

## 사용 AI 기술

- LLM 기반 일정 설계: 사용자 프로필(성별·연령·MBTI·목적·음식 취향·자연어 취향 메모)을
  프롬프트로 받아 장소 선택·일정 구성·추천 이유를 생성 (google/gemma-4-26b, LM Studio)
- 예산 배분·장소 선정·동선 최적화 하이브리드 알고리즘 (평점·근접도·예산 제약 스코어링 +
  최근접 이웃 동선 최적화 + 취향 필터). LLM 실패 시 자동 폴백
- TMAP POI·대중교통, TAGO 실시간 버스 도착정보, OSRM 보행 경로 등 6종 API 융합
