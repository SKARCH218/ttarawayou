## 판단이 필요한 것 (제가 임의로 정한 것들)

되돌리고 싶으면 말씀해 주세요.

| 항목 | 제가 정한 것 | 이유 |
|---|---|---|
| 취향 입력 방식 | **한 화면에 질문 하나** (이모지 중앙 + 질문·선택지 아래) | 요청대로. 단일 선택은 고르면 자동으로 다음 질문 |
| 로고 위치 | 인트로·설정 헤더·플랜 화면·파비콘 | 브랜드 자산은 `design-system/brand/` 에 정리 |
| 목적지 공개 여부 | **지역은 공개, 개별 장소는 도착 시 공개** | 기획서의 미결 사안. 사용자가 갈 지역은 알아야 실용적이고, 서프라이즈 정체성은 장소 단위로 유지 |
| 지도 타일 | OSM → **CARTO Positron** | OSM 공식 서버가 앱 트래픽을 차단해 지도가 깨졌음 |
| 앱 배포 형태 | 웹 데모 + Android APK | 규정상 모바일은 APK 허용, 웹은 심사위원 접속용으로 유지 |
| 예산 단위 | "토큰"(1토큰=1원) 유지 | 선결제 컨셉 표현. 실제 결제 없음을 명시 |
