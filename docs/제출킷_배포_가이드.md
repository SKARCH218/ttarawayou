# 프로덕트 URL 배포 가이드 (Render — 무료, 5분)

> 심사위원이 직접 접속·실행 가능한 URL이 **필수**입니다 (Figma·영상·캡처 불인정).
> Kotlin Spring 백엔드가 웹 데모까지 단일 jar로 서빙하므로 서비스 1개만 배포하면 됩니다.

## 1. Render 배포 (권장)

1. https://render.com → GitHub 계정(SKARCH218)으로 로그인
2. **New → Blueprint** → `SKARCH218/ttarawayou` 저장소 선택
3. 리포 루트의 `render.yaml`을 자동 인식 → **Apply** 클릭
4. 5~10분 후 `https://ttarawayou.onrender.com` 형태의 URL 발급
5. 접속해서 예산 입력 → 플랜 생성 → 🎬 데모 모드 동작 확인

### 환경 변수 (선택)

키가 없어도 내장 시드 데이터로 동작하도록 만들어져 있습니다.
실 데이터를 쓰려면 Render 대시보드 → Environment에서:

| 변수 | 용도 |
|---|---|
| `TMAP_APP_KEY` | 전국 실시간 POI·경로 (없으면 충남·대전 시드 폴백) |
| `DATA_GO_KR_API_KEY` | TAGO 실시간 버스 |
| `ODSAY_API_KEY` | 대중교통 경로 |

⚠️ **주의**: 무료 플랜은 15분 무접속 시 잠들었다가 첫 접속에 ~50초 걸립니다.
심사 기간(8/1~17)에는 https://uptimerobot.com 무료 모니터로 5분마다 핑을 걸어두면 항상 깨어 있습니다.

## 2. 긴급 대안 — Cloudflare 터널 (계정 불필요, 이 Mac 상시 가동 필요)

```bash
brew install cloudflared && cloudflared tunnel --url http://localhost:8080
```

→ 즉시 `https://xxxx.trycloudflare.com` URL 발급. 단, Mac이 꺼지면 죽으므로 신청서 제출 직전 임시용으로만.
